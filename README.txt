# 莫蘭迪藍歌單網站：最終 F 欄標籤清單版

## 正確邏輯

- A欄：歌名
- B欄：歌手
- C欄：每一首歌真正對應的標籤
- D欄：歌曲連結，可有可無
- F欄：網站上方「標籤按鈕清單」

## 很重要

F欄只是標籤清單，不會依照列數套到歌曲。

例如：
F3 = 男歌手
F4 = 女歌手
F5 = 古風

不代表第3首歌是男歌手、第4首歌是女歌手、第5首歌是古風。

歌曲要不要屬於「古風」，只看那首歌自己的 C 欄有沒有寫「古風」。

## 之後怎麼維護

### 想增加網站按鈕
在 F 欄新增標籤。

### 想刪除網站按鈕
從 F 欄刪掉標籤。

### 想讓某首歌被某個標籤篩到
在那首歌的 C 欄加入該標籤。

例如：
女歌手,古風

網站重新整理後就會同步。

## 新增歌曲
你之後新增更多列，只要 A欄歌名、B欄歌手有填，網站重新整理後就會自動讀到。
